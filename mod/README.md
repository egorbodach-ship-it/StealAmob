# Brainrot — мод под NeoForge 1.21.4

Порт девяти Paper-плагинов из этого репозитория в один клиент-серверный мод.
Старые плагины остаются в корне как источник истины по игровой логике: пока порт
не закончен, сверяться нужно с ними.

## Как собирать

Локально Gradle не нужен и wrapper в репозиторий не положен — сборка идёт в
GitHub Actions (`.github/workflows/mod.yml`), там Gradle ставится экшеном.
Достаточно запушить изменения в `mod/`, workflow запустится сам. Готовый jar
лежит в артефакте **brainrot-mod** на странице запуска.

Если хочется собрать у себя, понадобится JDK 21 и Gradle 8.12+:

```bash
cd mod
gradle build          # jar появится в mod/build/libs/
gradle runClient      # запуск клиента с модом для проверки
```

## Что делать, если билд красный

Версии вынесены в `gradle.properties` — `neoforge_version` и `moddev_version`.
Если в логе `Could not find artifact`, значит номер версии не существует:
актуальный список веток 21.4.x лежит на
<https://projects.neoforged.net/neoforged/neoforge>, поправить нужно только
`gradle.properties`.

Если ошибка компиляции — принеси лог целиком. В коде помечены комментариями
места, где сигнатуры менялись между версиями 1.21.x и я не мог проверить их
без компилятора: `ModEntities` (build от ResourceKey) и `BrainrotCommand`
(MobSpawnType против EntitySpawnReason).

## Что уже есть

Только каркас: точка входа, реестр энтити с одним тестовым брейнротом на
ванильной модели свиньи, клиентский рендерер, команда `/brainrot spawn` и CI.
Смысл этого этапа — убедиться что тулчейн, версия NeoForge и Java 21 сходятся,
прежде чем заливать 17 тысяч строк игровой логики.

WorldGuard, ActionBarAPI, LiteBans) в моде не используются: экономика, подписи
над мобами, подстановка текста и вставка построек пишутся своими средствами.
